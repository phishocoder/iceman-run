# JANICE ROOM

A mobile-first 16-bit browser arcade game inspired by public reporting around Drake's "Janice STFU" video and its Lykke Li "I Follow Rivers" sample/interpolation.

## Gameplay

- Swipe or use arrow keys to move between four lanes.
- Catch records and spotlights to build score, combo, room control, and Silence charge.
- Dodge talk bubbles and camera flashes.
- Use Silence when charged to clear the room.
- Chase a persistent local high score.

## Run

```bash
npm install
npm run dev
```

## Verify

```bash
npm run build
```

## Content guardrails

- The game uses original pixel art drawn in canvas.
- The background loop is an original Web Audio chiptune pattern locked to the uploaded reference tempo estimate of 112.75 BPM.
- It does not copy Drake lyrics, the song hook melody, album art, logos, or sample audio.
