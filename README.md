# ICEMAN RUN

A mobile-first 8-bit browser arcade game inspired by public reporting around Drake's "Janice STFU" and its Lykke Li "I Follow Rivers" sample/interpolation.

## Gameplay

- Swipe or use arrow keys to move between lanes.
- Collect ice records to build score, combo, reveal, and Melt charge.
- Grab heat sparks to charge Melt faster.
- Use Melt when charged to clear gossip/bot/camera/ice hazards.
- Pick up shields to survive crowded lanes.
- Reveal the date inside the ice block and chase a persistent local high score.

## Run

```bash
npm install
npm run dev
```

## Verify

```bash
npm run build
```

## Content guardrails

- The game uses original pixel art drawn in canvas.
- The background loop is an original Web Audio chiptune pattern inspired by the public chord palette, not the protected melody.
- It does not copy Drake lyrics, the song hook melody, album art, logos, or sample audio.
