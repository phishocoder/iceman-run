# ICEMAN RUN

A mobile-first 8-bit browser arcade game inspired by public reporting around Drake's "Janice STFU" and its Lykke Li "I Follow Rivers" sample/interpolation.

## Run

```bash
npm install
npm run dev
```

## Verify

```bash
npm run build
```

## Content guardrails

- The game uses original pixel art drawn in canvas.
- The background loop is an original Web Audio chiptune pattern.
- It does not copy Drake lyrics, the song hook melody, album art, logos, or sample audio.
